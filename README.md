# S.T.A.L.K.E.R.: Continuum

S.T.A.L.K.E.R.: Continuum is a standalone multiplayer mod for Windows that brings the S.T.A.L.K.E.R. trilogy campaigns and Advanced Weapon Pack together. Clear Sky is the first campaign in development. The playable Clear Sky story runs from the Marsh opening through recovery of the Freedom patrol's PDA in Dark Valley. Later areas and side quests are in development.

## Install and play

Use the S.T.A.L.K.E.R.: Continuum Launcher. It can find an existing installation or install into a folder you choose. Its Settings page edits game options, checks launcher and game versions, and verifies known game files. The Saves and Add-ons pages show what is present in the selected installation. The launcher offers Repair when it detects an incomplete install, and shows Update when a compatible update is available.

- [Download the Continuum Launcher](https://github.com/noahcabral/stalker-continuum/releases/tag/continuum-launcher-v1.0.6)
- [Launcher source and build instructions](tools/continuum-launcher)
- [Report an S.T.A.L.K.E.R.: Continuum issue](https://github.com/noahcabral/stalker-continuum/issues/new)

After a fresh installation, select **Update** if it appears before selecting **Play**. In game version **0.1.6**, **New Game**, **Last Save**, and **Load Game** host the campaign over LAN. On another PC on the same Wi-Fi or Ethernet network, open **Join LAN** and select the session. The launcher keeps existing saves when applying the update. [Game 0.1.6 release notes](https://github.com/noahcabral/stalker-continuum/releases/tag/awp-standalone-v0.1.6)

The earlier [LAN preview](https://github.com/noahcabral/stalker-continuum/releases/tag/v0.1.0-lan-preview.1) is a separate test release. The full trilogy campaign and its multiplayer acceptance testing are in progress.
